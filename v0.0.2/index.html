Executed release example¶

CI builds and installs this tag’s wheel, checks its Python and native versions, and runs the guide’s Mercier call with the public Solov’ev input. The original guide remains unchanged; its other examples are historical user-input workflows and require the stated input files.

>>> import gliss
>>> gliss.__version__ == gliss.version() == '0.0.2'
True
>>> import numpy as np
>>> from pathlib import Path
>>> equilibrium_export = Path('_static/solovev_q1.035.nc')
>>> s, d_mercier = gliss.mercier_profile(equilibrium_export)
>>> s.ndim == d_mercier.ndim == 1 and s.size == d_mercier.size > 0
True
>>> bool(np.all(np.isfinite(s)) and np.all(np.isfinite(d_mercier)))
True
